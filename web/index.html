Postie

A small native Gmail client for macOS

Built with SwiftUI for people who want a simple Mac email client without Electron, subscriptions, AI features, or workspace bloat.

View on GitHub

Features

  • Native SwiftUI macOS app
  • Gmail integration using Google Sign-In and the Gmail API
  • Inbox, Sent, Archive, Junk, and Trash
  • Conversation view with HTML email rendering
  • Compose, reply, reply all, and forward
  • Archive, trash, star, and read/unread actions
  • Local SQLite cache and incremental sync
  • Local search across loaded mail
  • Light and dark mode
  • Dock badge for unread Inbox mail

Privacy

Postie talks to Gmail directly from your Mac. There is no Postie server and no analytics. Read the privacy policy.
